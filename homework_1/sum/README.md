# Задача 2. Сумма

## Условие

На вход подаётся массив целых положительных чисел, разделённых пробелом. Найти максимальную сумму элементов массива, которая делится на 2.

Примеры:

| Вход | Выход | Пояснение |
|---|---|---|
| 5 7 13 2 14 | 36 | берём 2, 7, 13, 14 |
| 3 | 0 | 3 не делится на 2, поэтому в ответе 0 |

## Идея решения

Сначала считаем сумму всех элементов и одновременно запоминаем минимальный нечётный элемент.

Если общая сумма чётная, она и есть максимальный ответ: все числа положительные, поэтому добавление любого элемента только увеличивает сумму. Если сумма нечётная, из неё нужно убрать нечётную сумму. Самый маленький возможный вклад даёт один минимальный нечётный элемент, поэтому вычитаем именно его.

## Сложность

- Время — `O(n)`, где `n` — количество элементов: массив просматривается один раз.
- Память — `O(1)`: хранятся только сумма и минимальный нечётный элемент.

## Разбор на примере

Для массива `5 7 13 2 14`:

| Шаг | Значение |
|---|---:|
| Сумма всех чисел | `41` |
| Нечётные числа | `5, 7, 13` |
| Минимальное нечётное | `5` |
| Ответ | `41 - 5 = 36` |

Сумма `41` нечётная, поэтому исключаем `5`. Получается максимальная чётная сумма `36`.
