# Задача 3. Простые числа

## Условие

На вход подаётся целое число N. Найти количество простых чисел, меньших N.

Примеры:

| Вход | Выход | Пояснение |
|---|---|---|
| 10 | 4 | 2, 3, 5, 7 |
| 1 | 0 | |

## Идея решения

Используется решето Эратосфена. Создаём массив признаков для чисел от `0` до `N - 1`: сначала считаем все числа простыми, кроме `0` и `1`.

Затем для каждого ещё не вычеркнутого числа `p` помечаем составными все его кратные, начиная с `p * p`. Более ранние кратные уже были отмечены меньшими делителями. В конце остаётся посчитать элементы со значением `True`.

## Сложность

- Время — `O(N log log N)`: решето помечает кратные простых чисел.
- Память — `O(N)`: хранится массив признаков для чисел, меньших `N`.

## Разбор на примере

Пусть `N = 20`. В начале потенциально простыми считаются числа от `2` до `19`.

| Делитель `p` | Помечаем составными числа |
|---:|---|
| 2 | 4, 6, 8, 10, 12, 14, 16, 18 |
| 3 | 9, 15, 18 |
| 4 | пропускаем: число уже составное |

Достаточно проверить делители до квадратного корня из `19`. Неотмеченными остаются `2, 3, 5, 7, 11, 13, 17, 19`, поэтому ответ — `8`.
