# Tracer

## Условие

Декоратор показывает вход в рекурсивный вызов, глубину стека отступом и возврат с результатом. Функция сохраняет аргументы и возвращаемое значение.

## Идея

Перед вызовом печатаем имя и `repr` аргументов, увеличиваем глубину. После успешного вызова печатаем результат. В `finally` возвращаем прежнюю глубину, поэтому исключение не ломает последующие трассировки. `ContextVar` хранит глубину в текущем контексте, в том числе для вложенных вызовов разных декорированных функций. `wraps` сохраняет имя и документацию.

## Пример

```python
@tracer
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

factorial(3)
```

```text
-> factorial(3)
  -> factorial(2)
    -> factorial(1)
    <- factorial = 1
  <- factorial = 2
<- factorial = 6
```

Строка со стрелкой вправо – положенный в стек вызов, со стрелкой влево – возврат и снятие кадра. При исключении печатается `!!`, затем исключение передаётся вызывающему коду.

## Сложность

Кроме форматирования и вывода, O(1) действий на вызов и O(h) кадров при глубине h. С учётом реального вывода время O(L), где L – суммарное число напечатанных символов. Для линейной рекурсии отступы сами могут дать O(h²) символов. Декоратор предназначен для обычных синхронных функций, не для генераторов и корутин.
