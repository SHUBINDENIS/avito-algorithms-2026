# Iterative

Mergesort начинает с блоков длины 1. На каждом проходе сливаем соседние блоки в буфер, выбирая меньший из двух первых оставшихся элементов. Последний блок без пары переносится целиком. Меняем списки местами и удваиваем ширину, пока весь список не станет одним отсортированным блоком.

Quicksort берёт последний элемент диапазона за опорный. Разбиение ставит его на место: слева элементы меньше, справа – больше или равны. Большую часть откладываем в стек, меньшую обрабатываем сразу. Диапазоны не пересекаются, поэтому следующие разбиения сохраняют позиции уже поставленных опорных элементов. Обе сортировки возвращают новый список.

## Сложность

- **Mergesort:** O(n log n) времени – O(log n) проходов по n элементов. O(n) памяти на копию и буфер.
- **Quicksort:** в среднем O(n log n) на случайной перестановке разных элементов, поскольку разбиения в среднем дают O(log n) уровней. В худшем случае O(n²), когда диапазон уменьшается на один элемент. O(n) памяти на копию и O(log n) на стек: при каждом вложенном откладывании продолжаем работу с частью размером не больше половины.

## Пример

Вход: `[6, 2, 5, 1, 4, 2, 3]`.

Mergesort, блоки после каждого прохода:

```text
1: [2, 6] | [1, 5] | [2, 4] | [3]
2: [1, 2, 5, 6] | [2, 3, 4]
4: [1, 2, 2, 3, 4, 5, 6]
```

Quicksort, индексы с нуля, границы включены. Вершина стека справа.

| Диапазон | Опорный | Список после разбиения | Стек |
|---|---:|---|---|
| 0–6 | 3 | `[2, 1, 2, 3, 4, 5, 6]` | `[(0, 2)]` |
| 4–6 | 6 | `[2, 1, 2, 3, 4, 5, 6]` | `[(0, 2), (4, 5)]` |
| 4–5 | 5 | `[2, 1, 2, 3, 4, 5, 6]` | `[(0, 2)]` |
| 0–2 | 2 | `[1, 2, 2, 3, 4, 5, 6]` | `[]` |
