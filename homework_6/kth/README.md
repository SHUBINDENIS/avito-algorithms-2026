# K-th

Чтобы найти k-й по величине элемент, ищем значение, которое стояло бы на индексе `len(nums) - k` при сортировке по возрастанию. Повторы считаются отдельно.

Quickselect выбирает случайный опорный и делит текущий диапазон на элементы меньше, равные и больше него. Блоки уже стоят в порядке своих рангов. Если искомый индекс в блоке равных, возвращаем опорный. Иначе оставляем только ту часть, в которой лежит индекс. Работаем с копией, без сортировки и куч. Неверный k даёт `ValueError`.

## Сложность

В среднем O(n) времени. С постоянной вероятностью опорный попадает в среднюю половину рангов, тогда диапазон сокращается минимум на четверть. Ожидаемая сумма размеров разбиений линейна. В худшем случае O(n²), если каждый раз выбирается крайний элемент. Память O(n) на копию и O(1) сверх неё.

## Пример

`[3, 2, 3, 1, 2, 4, 5, 5, 6]`, `k = 4`, ищем индекс 5. Для примера выбираем опорные с индексов 0 и 6.

| Диапазон | Опорный | После разбиения | Следующий шаг |
|---|---:|---|---|
| 0–8 | 3 | `[2, 1, 2, 3, 3, 5, 5, 6, 4]` | Равные на 3–4, идём вправо. |
| 5–8 | 5 | `[2, 1, 2, 3, 3, 4, 5, 5, 6]` | Равные на 6–7, остаётся индекс 5. |

На индексе 5 стоит **4**.

## Тесты

Оба примера из условия, один элемент, минимум и максимум, повторы, неверные k. На случайных списках сверяем каждый ранг с отсортированным эталоном. Пример выше проверяется с фиксированными опорными.
