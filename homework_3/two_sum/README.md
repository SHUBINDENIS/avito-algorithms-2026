# Задача 1. Two sum

## Условие

Дан массив целых чисел `arr` и число `k`. Нужно найти индексы двух разных элементов, сумма которых равна `k`. По условию подходящая пара ровно одна.

Индексы считаются с нуля.

| arr | k | Ответ |
|---|---:|---|
| `[1, 3, 4, 10]` | 7 | `1 2` |
| `[5, 5, 1, 4]` | 10 | `0 1` |

Функция возвращает кортеж `(i, j)`, где `i < j`. При запуске программы индексы выводятся через пробел.

## Идея решения

Проходим массив один раз. В словаре храним уже встреченные значения и их индексы.

Для текущего числа `x` нужно найти число `k - x`. Если оно уже есть в словаре, возвращаем его индекс и текущий индекс.

Если нужного числа нет, добавляем `x` в словарь и продолжаем.

Проверка выполняется до добавления текущего элемента. Поэтому один элемент не используется дважды: для `[5]` и `k = 10` пара `(0, 0)` не появится.

Найденный в словаре индекс всегда меньше текущего, поэтому ответ сразу получается в порядке возрастания.

Если пары нет, функция вызывает `ValueError`. Это дополнительная проверка для входов вне гарантии условия.

## Сложность

Пусть `n` — длина массива.

| Подход | Время | Дополнительная память |
|---|---|---|
| Перебор всех пар | O(n²) | O(1) |
| Один проход со словарём | O(n) в среднем | O(n) |

Словарь позволяет искать дополнение в среднем за O(1), вместо повторного перебора массива. За это платим дополнительной памятью.

## Разбор на примере

`arr = [1, 3, 4, 10]`, `k = 7`.

Словарь показан до обработки текущего элемента.

| i | x | Ищем k − x | Словарь | Найдено? |
|---:|---:|---:|---|---|
| 0 | 1 | 6 | `{}` | Нет, добавляем `1: 0` |
| 1 | 3 | 4 | `{1: 0}` | Нет, добавляем `3: 1` |
| 2 | 4 | 3 | `{1: 0, 3: 1}` | Да, возвращаем `(1, 2)` |

На третьем шаге найдено число `3` с индексом `1`. Текущее число `4` имеет индекс `2`. Их сумма равна `7`, поэтому дальше массив обходить не нужно.

## Тесты

Проверяются:

- оба примера из условия;
- одинаковые числа на разных позициях;
- отрицательные числа;
- два нуля;
- пара в конце массива;
- массив из двух элементов;
- отсутствие пары, пустой массив и один элемент.
