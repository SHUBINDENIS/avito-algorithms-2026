# Задача 2. Anagrams

## Условие

Дан список слов. Нужно объединить анаграммы в группы.

Анаграммы состоят из одинаковых букв с одинаковым количеством повторений, но порядок букв может различаться.

Пример:

```text
Вход: ["eat", "tea", "tan", "ate", "nat", "bat"]
Выход: [["bat"], ["nat", "tan"], ["ate", "eat", "tea"]]
```

Порядок групп и слов внутри них не важен.

## Идея решения

Для каждого слова сортируем буквы и соединяем их в строку. Полученная строка — ключ группы.

Например, у `eat`, `tea` и `ate` одинаковый ключ `aet`. Значит, эти слова нужно положить в одну группу.

В словаре ключу соответствует список слов. Если ключ встречается впервые, создаём пустую группу, затем добавляем слово.

В конце возвращаем списки из значений словаря.

Ключ — строка, потому что она хешируемая. Список, который возвращает `sorted`, нельзя использовать ключом словаря.

## Сложность

Пусть `N` — количество слов, а `L` — максимальная длина слова, но не меньше 1.

- Время: O(N · L · log(L + 1)) в среднем, обычно записывается как O(N · L log L).
- Дополнительная память: O(N · L) для ключей и списков групп.

Главная затрата времени — сортировка букв каждого слова.

Если слова содержат только 26 строчных латинских букв, можно использовать ключ из 26 счётчиков. Тогда построение ключей займёт O(N · L). Здесь сортировка выбрана как простой вариант без ограничения на алфавит.

## Разбор на примере

| Слово | Ключ | Группа после добавления |
|---|---|---|
| `eat` | `aet` | `["eat"]` |
| `tea` | `aet` | `["eat", "tea"]` |
| `tan` | `ant` | `["tan"]` |
| `ate` | `aet` | `["eat", "tea", "ate"]` |
| `nat` | `ant` | `["tan", "nat"]` |
| `bat` | `abt` | `["bat"]` |

Итоговый словарь:

```python
{
    "aet": ["eat", "tea", "ate"],
    "ant": ["tan", "nat"],
    "abt": ["bat"],
}
```

Результат:

```python
[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

Этот ответ совпадает с примером по составу групп.

## Тесты

Проверяются:

- пример из условия;
- пустой список;
- одно слово;
- пустая строка;
- одинаковые слова;
- отсутствие анаграмм;
- все слова в одной группе;
- одинаковые буквы с разным количеством повторений.

Перед сравнением сортируются слова внутри групп и сами группы. Поэтому тесты не зависят от порядка ответа, но учитывают повторения слов.
